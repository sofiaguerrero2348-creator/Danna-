Simplee — campaña digital
Proyecto académico de una página web responsive para una campaña de moda.
Estructura
- index.html: contenido y estructura de la página.
- styles.css: estilos y adaptación a móviles.
- assets/campana-vestido-naranja.webp: imagen de campaña optimizada.
Vista previa local
Abre index.html en un navegador. Para probar rutas y comportamiento de forma más parecida a un servidor, usa la extensión Live Server de Visual Studio Code.
Publicar con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo simplee-campana.
2. Sube index.html, styles.css, la carpeta assets y este README.
3. En el repositorio entra a Settings → Pages.
4. En Build and deployment, selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta / (root), y guarda.
6. Espera a que GitHub Pages publique el sitio. El enlace aparecerá en la misma sección de Pages.
